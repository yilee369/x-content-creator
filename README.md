# X / Twitter 商业内容创作 Skill - 使用指南

## 这是什么

把任何零散素材(金句、故事、观察、数据、案例)自动转化为 X 上的高质量商业内容。

输入随便丢:语音转文字、灵感闪现、复盘片段、客户对话、数据复盘——Skill 会自动判断:
1. 这是哪种素材(7 种类型)
2. 撑不撑得起 Thread,还是只能写单推
3. 选 2-3 个最适合的角度,各出一版让你选

## 怎么用(3 种方式)

### 方式 1:Claude Projects(推荐)

1. 打开 Claude.ai,新建一个 Project
2. 取名"X 内容创作"
3. 把 `SKILL.md`、`references/templates.md`、`references/classification.md`、`references/quality-rules.md` 全部上传到 Project 的知识库
4. 在 Project 的 Custom Instructions 里写:"每次对话都按 SKILL.md 的工作流处理我的素材"
5. 以后每次有灵感,在这个 Project 里开对话,丢素材就行

### 方式 2:Claude Code(适合开发者)

把整个 `x-content-creator/` 文件夹放到你的 skills 目录下,Claude Code 会自动识别并在合适的时候调用。

### 方式 3:单次对话使用

如果你只想偶尔用一次,不想搭 Project:
1. 复制 `SKILL.md` 的全部内容
2. 粘贴到 Claude 对话开头作为系统提示词
3. 然后直接丢素材

## 文件结构说明

```
x-content-creator/
├── SKILL.md                          ← 主工作流(每次都加载)
└── references/
    ├── classification.md             ← 7 种素材类型详细判断规则
    ├── templates.md                  ← 6 个模板的完整结构
    └── quality-rules.md              ← 字符数 + AI 腔禁用词清单
```

主 SKILL.md 会按需调用 references/ 里的文件,不会一次性把所有内容塞进上下文。

## 工作流程一览

```
你输入素材
    ↓
[Step 1] 自动判断中英文
    ↓
[Step 2] 分类(7 种类型)
    ↓
[Step 3] 评估厚度(够不够撑 Thread)
    ↓
[Step 4] 选 2-3 个互补的模板
    ↓
[Step 5] 各生成一版,带配图建议
    ↓
[Step 6] 你选定后做最后优化
    ↓
附送:发布 4-6 小时后的二次引用建议
```

## 实际效果

输入像"赚钱就是用软文铺流量平台"这样 1 句话的素材,Skill 会:

1. 识别出这是"金句/暴论"类型(类型 A)
2. 评估为"薄"素材,不能撑 Thread
3. 出 3 个不同角度的单推:
   - 直球暴论版
   - 故事化包装版
   - 反问诱发评论版

输入像"上个月签下第一个年费 30 万的客户,前后磨了 4 个月"这样的故事素材,Skill 会:

1. 识别出这是"经历故事"类型(类型 B)
2. 如果素材厚 → 出完整故事 Thread
3. 如果素材薄 → 出 3 版:Thread / 单推浓缩版 / 反共识切入版

## 维护和迭代

用一段时间后,如果你发现:

- **某些类型识别不准** → 告诉 Claude:"修改 classification.md,把 X 类的判断规则改成 Y"
- **某个模板不好用** → 告诉 Claude:"改 templates.md 里的模板 N,我希望它..."
- **AI 腔词漏了** → 告诉 Claude:"在 quality-rules.md 的禁用词里加上 X、Y、Z"

Skill 是活的,根据你的实际使用反馈持续优化。

## 几个关键设计

**为什么是 2-3 个版本而不是 1 个**:商业内容受众判断力强,标题/角度差 5% 点击率就差很多。让你来选比 AI 替你决定好。

**为什么有"素材厚度评估"这一步**:绝大部分 AI 文案工具的最大问题是不管什么素材都给你写 10 条。真正好的 Thread 需要素材撑得起。这一步就是为了避免出"空话 Thread"。

**为什么强制配图建议**:推文加视觉素材后转发率提升约 78%。但库存图(unsplash)反而降可信度。Skill 强制你用真实截图。

**为什么有"二次创作建议"**:发布后 4-6 小时引用转发自己加一个更尖锐的观点,能让原推文传播翻倍。这是大部分人忽略的免费流量。

## 注意事项

- Skill 不会替你编造数字。如果你的素材没有具体数字,它会引导你回到"金句"路线,而不是凭空造数据
- Skill 不会用 hashtag(除非你明确要求),因为 X 上 hashtag 已经过时
- Skill 默认不写 emoji,商业内容用 emoji 显得廉价

## 反馈和优化

发现什么模板效果不好、什么类型判断错了、什么 AI 腔词漏了——直接告诉 Claude 你想改哪个文件、改哪一行,Skill 会跟着你的实际数据进化。
